## 📝 Project Overview
This project implements low-level control of a **64x32 RGB LED Matrix** using a **Raspberry Pi**. It features custom algorithms for geometric transformations including:
* **Translation:** Moving graphics across the coordinate plane.
* **Rotation:** Implementing 2D rotation matrices.
* **Scaling & Shearing:** modifying sprite dimensions and skew in real-time.

## 🛠️ Hardware & Tools
* **Hardware:** Raspberry Pi 4, Adafruit RGB Matrix Bonnet, 64x32 LED Matrix.
* **Language:** Python 3.
* **Libraries:** `rgbmatrix` (Hazen Sextro), `numpy`.

## 📂 File Structure
* `Translation.py` - Logic for linear movement updates.
* `Rotation.py` - Trigonometric calculations for pixel rotation.
* `Scaling.py` - Algorithms for resizing the display buffer.
